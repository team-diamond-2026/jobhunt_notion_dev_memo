## UI方針
- 左サイドバーで主要画面へ遷移
- 中央にメインコンテンツ
- モバイルではタブまたはドロワーに切り替える
- Notion風の余白とシンプルなUIを意識する

## 実装済み画面のレスポンシブ対応（Issue #51）

- 対象: ログイン・アカウント作成、ホーム、企業一覧
- 640px未満ではヘッダーを縦に並べ、企業一覧のナビゲーションを2列で表示する
- ホームの情報カードは768px未満で1列、企業登録フォームは640px未満で1列にする
- スマホではカードの余白と見出しを小さくし、登録・企業一覧へのボタンを横幅いっぱいに表示する
- ボタン・リンク・入力欄は高さ44px以上とし、スマホの入力文字サイズは16pxにする
- 長い表示名・メールアドレス・ユーザーID・企業名・業界・メモは折り返し、メモの改行を保持する
- 画面の最小高さには動的ビューポートを使い、スマホのブラウザバーの高さ変化に追従する
- 現在の主要導線は少数のため、常に表示する。画面追加に伴うタブ・ドロワー化は今後検討する

### 表示・操作の確認項目

- 320 / 375 / 390 / 640 / 768 / 1280px幅でページ全体の横スクロールが発生しない
- 長い英数字のメールアドレス・企業名・URLを含むメモでもカード幅を超えない
- スマホのログイン・アカウント作成切り替え、企業登録フォーム、ホームへの遷移、ログアウトを操作できる
- PCではヘッダーが横並びになり、ホームのカードと企業登録フォームが2列で表示される
