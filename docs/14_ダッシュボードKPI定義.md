# ダッシュボードKPI定義

Issue #29で採用するMVPの進捗KPIと集計条件です。

## 採用するKPI

| KPI | データ元 | 集計条件 |
| --- | --- | --- |
| 登録企業数 | `companies` | ユーザーが登録した企業の総数 |
| 未応募 | `companies.selection_status` | `未応募` の企業数 |
| ES提出 | `companies.selection_status` | `ES提出` の企業数 |
| Webテスト | `companies.selection_status` | `Webテスト` の企業数 |
| 面接中 | `companies.selection_status` | `一次面接`、`二次面接`、`最終面接` の企業数 |
| 内定 | `companies.selection_status` | `内定` の企業数 |

`辞退` は選考ボード・企業編集・企業詳細で独立したステータスとして扱う。

選考ステータスは、企業一覧・選考ボードと同じ値を使用する。これにより、ダッシュボードの数値と実データの表示を一致させる。

## タスク数を今回採用しない理由

タスク数はMVPの候補だが、現時点ではタスクの作成・完了状態を操作する画面がない。今回のKPIには含めず、タスク管理の保存・取得・完了状態が確定した後に追加する。追加時は未完了の定義と対象期間を別Issueで決める。

## 表示方針

- データが0件の場合も、各KPIを `0` と表示する。
- 各カードに集計対象の説明を表示し、数値の意味を画面上で確認できるようにする。
- PCでは4列、狭い画面では1列または2列に折り返し、カード内のラベルと数値を読めるようにする。
