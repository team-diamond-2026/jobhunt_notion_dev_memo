# 04 機能一覧

## コア機能

### 1. 認証機能
- 新規登録
- ログイン
- ログアウト
- パスワード再設定

### 2. ダッシュボード
- 今週の締切表示
- 直近の面接予定表示
- エントリー中企業数
- 未完了タスク数
- 選考状況サマリー

### 3. 企業管理
- 企業の新規作成
- 企業情報の編集
- 業界、志望度、選考状況の登録
- 企業ごとのメモ保存
- 企業名のキーワード検索（Issue #48）
  - 検索ボタンまたはEnterキーで、企業名の部分一致検索を実行する
  - 前後の空白を除き、英字の大文字・小文字を区別せずに検索する
  - 検索語はURLの `keyword` パラメーターに保持する（`q` パラメーターにも対応）
  - 検索中は検索語と件数を表示し、一致する企業がない場合はメッセージを表示する
  - 企業名が空欄・空白のみの場合は企業名で絞り込まない
  - 「リセット」を選択すると、業界・選考状況も含む検索条件を解除して全件表示する

### 4. 選考管理
- ステータス管理
- カンバン表示
- 一覧表示
- ステータス変更履歴
- 選考ボードでのステータス変更（Issue #47）
  - 企業一覧の「選考ボード」から `/companies/board` を開く
  - 登録時と同じ9ステータスを列として表示し、企業カードを別の列へドラッグ＆ドロップすると保存する
  - ドラッグ中は移動先の列を強調し、空の列にもドロップできる
  - スマホ・キーボードではカード内の「移動先」セレクトから変更できる。スマホでは列を縦に並べ、表示するステータスを絞り込める
  - 既存の選考管理と同じく、前の段階への変更を禁止する
  - 保存中は追加の変更を止め、失敗時はエラーを表示して選考状況を再取得する。別の画面で情報が更新されていた場合は、表示時の変更を保存せず最新の状態を案内する
  - 通信が切断されて保存結果が不明な場合は、ボードを再読み込みするまで移動を止める
  - 更新はログイン中のユーザーが所有する企業に限定し、企業一覧にも反映する
  - 旧ステータスは共通の表示ルールに従って読み替える。対応する値がない企業は「未応募」列に表示する
  - 列内の並べ替えやステータス変更履歴の保存は対象外

- 企業別ES紐付け
